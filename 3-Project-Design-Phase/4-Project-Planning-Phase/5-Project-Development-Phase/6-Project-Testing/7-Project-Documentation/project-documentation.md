# Project Documentation

## Project Name
Pocket Smart AI: Your Smart Budget and Recommendation Assistant

## Project Objective
To provide AI-powered product and service recommendations based on the user's budget and requirements.

## Key Features

- Budget-based recommendations
- Product and service suggestions
- AI-powered recommendation system
- Simple user interface
- Personalized recommendations

## Technologies Used

- Python
- HTML
- Flask
- Gemini API

## Project Outcome

The system helps users make suitable recommendations according to their requirements and available budget.
