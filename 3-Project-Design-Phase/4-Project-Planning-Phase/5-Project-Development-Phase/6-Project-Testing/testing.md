# Project Testing

## Testing Objectives

- Verify that the application loads correctly.
- Verify that user inputs are accepted.
- Verify that the budget is processed correctly.
- Verify Gemini API connectivity.
- Verify that recommendations are generated.
- Verify that recommendations are displayed correctly.

## Test Cases

| Test Case | Expected Result |
|---|---|
| Enter valid budget | Budget is accepted |
| Select a category | Category is accepted |
| Submit requirements | Recommendation process starts |
| Gemini API request | AI response is received |
| Display recommendation | Results are shown to the user |
